# 凤王铃之塔地图资产

These production files are the individually layered, transparent assets created and approved in `artifacts/hooh-arena-concept/` for this game. They are original project artwork generated for this project with OpenAI image generation; the source prompts and concept remain in that directory. No third-party source assets are included.

- `hooh-tower-foreground.webp` — 1672×941 RGBA tower and summit platform, in front of the clouds.
- `hooh-cloud-1.png` through `hooh-cloud-12.png` — individually drawn transparent cloud sprites; independently positioned and animated behind the tower.

Cloud sprites use linear texture filtering to preserve their soft pixel-art edges. The tower is drawn at its source aspect ratio.
