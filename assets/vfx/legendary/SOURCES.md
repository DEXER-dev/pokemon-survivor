# Legendary active-skill materials

The original archives under `source/` are kept unchanged. Every listed OpenGameArt page marks the work CC0. The runtime atlas uses selected frames from these archives; source colors and transparency are retained. Pure Projectile frames are downscaled from 200×200 to 150×150 to fit the shared atlas cells.

| Archive | Author / license | Runtime selection |
|---|---|---|
| `cethiel-arcane-effect.zip` | [Cethiel · CC0](https://opengameart.org/content/arcane-magic-effect) | Arcane sequence 01, Mewtwo |
| `cethiel-water-effect.zip` | [Cethiel · CC0](https://opengameart.org/content/water-magic-effect) | Water sequences 03–05, Lugia and Kyogre |
| `cethiel-earth-impact.zip` | [Cethiel · CC0](https://opengameart.org/content/earth-impact-magic-effect) | Earth sequences 03–04, Groudon |
| `cethiel-cosmic-time.zip` | [Cethiel · CC0](https://opengameart.org/content/cosmic-time-magic-effect) | Clock and vortex sequences 02 and 05, Dialga and Palkia |
| `cethiel-pure-projectile.zip` | [Cethiel · CC0](https://opengameart.org/content/pure-projectile-magic-effect) | Final impact row, Arceus |
| `cethiel-purple-weapon-slash.zip` | [Cethiel · CC0](https://opengameart.org/content/weapon-slash-effect) | Purple slash sequence 04, Palkia |

`legendary-material-atlas.png` is generated by `game/tools/build-legendary-vfx-atlas.py`. `manifest.json` records frame bounds. Rayquaza has no downloaded creature-specific artwork in this set; its active effect uses the game's existing dragon and rift glyphs.
