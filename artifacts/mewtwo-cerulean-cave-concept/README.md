# 华蓝洞窟深处 · 超梦地图概念

这是一张独立的超梦 BOSS 地图概念预览，尚未接入正式游戏场景。

地图取向是封闭岩洞深处：蓝灰色石地与洞壁建立幽深感，巨石、边缘水洼和少量淡紫晶脉收在外围，中央留出大块战斗空间。超梦使用项目现有精灵图；淡紫色气场参考项目当前的超能力技能色。页面可以切换遭遇构图/纯场地、开关洞顶光影与环境微动，并播放超能力脉冲或开局演出。华丽版开局时，全屏四角、洞壁与地面的光点先汇向超梦，周身能量核心逐渐蓄亮，接着释放一次局部紫白闪光与短促放射光束；超梦随能量峰值升起，亮度回落后恢复成稳定气场。特效集中在超梦周围，不铺满全屏。

地点方向参考超梦出现在华蓝洞窟深处的系列设定，但背景是原创概念画，不是原作地图复刻。底图为本项目生成的概念素材。
