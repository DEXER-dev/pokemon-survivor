# 华蓝洞窟深处 · 超梦地图概念

这是一张独立的超梦 BOSS 地图概念预览，尚未接入正式游戏场景。

地图取向是封闭岩洞深处：蓝灰色石地与洞壁建立幽深感，巨石、边缘水洼和少量淡紫晶脉收在外围，中央留出大块战斗空间。超梦使用项目现有精灵图；淡紫色气场参考项目当前的超能力技能色。页面可以切换遭遇构图/纯场地、开关洞顶光影与环境微动，并播放超能力脉冲或开局演出。华丽版开局时，72颗粒子分批从四边、四角和地面各处持续汇向超梦；它的紫白描边随蓄能逐渐增强，最后一批粒子收束后才爆发。爆发结束后切入战斗状态并显示 BOSS 血条。特效集中在超梦周围，不铺满全屏。

地点方向参考超梦出现在华蓝洞窟深处的系列设定，但背景是原创概念画，不是原作地图复刻。底图为本项目生成的概念素材。
