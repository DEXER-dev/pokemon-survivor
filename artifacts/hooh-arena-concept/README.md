# 铃之塔顶层 · 凤王战斗地图概念

这是凤王 BOSS 战的独立场景预览，尚未接入正式关卡。场景保留铃之塔顶层外部战斗平台，并在平台下方露出木构楼身与层叠飞檐，避免画面像悬浮擂台；像素风格参照游戏内凤王精灵图。

## 设计依据

- 以城都地区的铃之塔（旧称钟之塔）顶层为意象：顶层屋脊平台、朱红木构、铜铃，以及平台下方连续可见的多层塔身与瓦檐。
- 战斗平台中央保持宽阔、低对比、无障碍；下方塔身仅作远景构图，不进入角色走位区域。
- 相机使用俯视单屏构图，像素块面与项目精灵图的颗粒靠拢；不模拟 GBA 屏幕、扫描线或瓷砖网格覆盖层。
- 凤王使用项目已有的 `assets/icons/HOOH.png` 精灵图；训练家使用 `assets/player/NPC_198_Lucas.png`。
- 预览底图为原创生成的概念背景，不是原作地图复刻。按钮可切换纯场地/遭遇构图、环境微动和天光，并播放凤王从画面上方高空逐渐放大俯冲、落地后扬起羽火碎片的开场演出。页面默认静音；可通过“播放凤王降临”按钮重播。URL 加 `motion=full&autoplay=1` 可在预览中自动播放完整动效，默认状态仍遵循系统减弱动态设置。
