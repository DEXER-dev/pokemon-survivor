# 天空之柱顶层战斗地图预览

这是给裂空座 BOSS 地图的美术方向预览，尚未接入正式游戏场景。

## 原作参考

- 《宝可梦 绿宝石》天空之柱顶层的遭遇房间：蓝色石砖地面、沿边重复的浅色石块/石柱纹样、南侧棕金门槛与出口。
- 预览的中央区域留空，用于裂空座、玩家走位和技能范围提示；边缘纹样营造封闭室内空间。

预览页提供“遭遇构图 / 纯场地”切换，可对比角色比例和地图本身；“上下光影”切换顶部柔和冷光到南侧渐暗的纵向层次，“环境微动”可开关地砖掠光、石纹微闪与少量上浮尘点。“播放开场演出”展示上半屏被完整连续云海笼罩，裂空座悬在上半部；前景云团向两侧散开后，完整云幕整体上升淡出，显现BOSS并露出下半部战斗空间。播放中可跳过，之后可重播。“播放苏醒演出”单独展示从南侧入口向裂空座聚拢后消散的短气流。

纵向光影形成清楚的顶部亮、南侧暗层次；云层开场与其他动画都是为战斗地图新增的设计概念，不是《绿宝石》原作自带效果。开场在系统允许动态效果时自动播放；若系统启用了减少动态效果，页面停留在战斗构图，由用户主动播放。云层只在开场覆盖上半屏，散去后不遮挡走位。
