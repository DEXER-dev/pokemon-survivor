# 天空之柱顶层战斗地图预览

这是给裂空座 BOSS 地图的美术方向预览，尚未接入正式游戏场景。

## 原作参考

- 《宝可梦 绿宝石》天空之柱顶层的遭遇房间：蓝色石砖地面、沿边重复的浅色石块/石柱纹样、南侧棕金门槛与出口。
- 预览的中央区域留空，用于裂空座、玩家走位和技能范围提示；边缘纹样营造封闭室内空间。

预览页提供“遭遇构图 / 纯场地”切换，可对比角色比例和地图本身；“环境微动”可开关地砖掠光、石纹微闪与少量上浮尘点，“播放苏醒演出”展示从南侧入口向裂空座聚拢后消散的短气流。

这些动画是为战斗地图新增的设计概念，不是《绿宝石》原作自带效果；常态保持低频、低对比，不遮挡角色、地砖或技能范围。页面遵循系统减少动态效果偏好，用户可以用按钮主动开启预览动效。
